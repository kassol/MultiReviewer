# MultiReviewer

Agent-driven, multi-model code review for self-hosted Gitea (GitHub support planned).

Real coding agents open files and explore context. Multiple models review in parallel. Cross-validation between models filters false positives. Incremental re-checks keep reviews convergent instead of endlessly divergent.
